# 主动事件增强 (SystemEventBoost)

以官方「主动事件」机制为基础进行增强，让 AI 的自主活动更聪明、更懂主人。完整继承官方的周期报点算法（基础间隔 ± 随机偏移 × 翻倍次数），并在此基础上叠加了定时任务、自定义报点模式与五种可叠加的陪伴模式，全部可由 AI 通过自然语言自主开启与关闭。

## 功能特性

- **定时任务**：支持循环任务（每天 / 每周几固定时分触发）与临时任务（N 分钟后触发一次），让 AI 定时提醒主人或自主做任何事；**临时任务触发后自动删除**（不留禁用残骸，AI 也无需手动清理）
- **自定义报点模式**：可创建多个自定义报点提示词（如「学习模式」「新闻模式」），与默认官方报点自由切换；每个模式可单独开启**独立计时**（各自一套报点间隔/随机偏移/倍数/最大翻倍次数，模式之间的报点时间互相独立），不开启则沿用全局活跃机制
- **游戏陪伴模式**：按自定义间隔主动查看屏幕游戏画面，给予鼓励与建议（AI 自动使用深度视觉）
- **睡眠模式**：设定时间内 AI 不再主动活动，直到主人发消息或倒计时结束自动恢复；可开关「群聊静默」——睡眠期间群聊消息替换为静默占位，AI 不回复
- **群聊 / 私聊消息重置倒计时**：默认开启，收到群聊消息、或非主人的私聊消息都视为互动并重置周期报点倒计时（睡眠中除外）；可关闭，让这些消息不再打断自主活跃节奏。事件由 QQ 插件（≥ 4.4.0）通过官方系统事件接口送达本插件（见下条）
- **接管官方系统事件接口**：实现官方 `ISystemEventService`，作为官方「主动事件」插件的替代实现。关闭官方插件后，QQ 插件的「收到群聊/私聊消息重置倒计时」会直接落到本插件，本插件的开关才能生效；旧版 QQ 插件下本插件仍用消息文本兜底识别（两条路径自动去重）
- **DeepSeek 峰谷模式**：高峰时段（默认北京时间 9-12 点、14-18 点，周一至周五）自动停止自主活跃节省资源；时段与生效星期（逐日开关）均可自定义；**法定节假日自动豁免**（假期 DeepSeek 按谷价计费，峰谷不生效、照常自主活跃），节假日表内置 2026 年官方放假安排且可自由增删/在线校准
- **勿扰模式**：AI 自主活动但不打扰主人（禁止 speak/qchat 标签），可自定义允许 AI 做的事
- **撒娇模式**：更粘人主动找主人，最短活跃间隔 20 秒 + 智能节流（无互动自动拉长间隔防空转）
- **工作模式**：像专业 Agent 一样执行任务——AI 先输出 `<plan>` 编号计划，系统解析为步骤队列逐步推进，每步完成用 `<WorkStepDone/>` 进入下一步，支持暂停/恢复/中止/跳转/查看计划；单步超时自动提醒防卡死；工作时自动注入 Python/进程/文件/浏览器/搜索/Skill/AlifeMcp 工具提示，配合官方工具完成写代码/改文件/跑脚本等真实任务
- **模式总开关**：游戏陪伴/睡眠/勿扰/撒娇/峰谷/工作/自定义报点/定时任务/活跃间隔/定点报时 十项总开关，关闭后该模式函数不再暴露给 AI、提示词也不再注入
- **隐式注入开关**：开启后函数文档不直接注入系统提示词，AI 先调用 `<systemeventboost/>` 按需加载（省 token，渐进式）
- **对话窗口倒计时挂件**：实时显示距下次自主活跃的倒计时，每个激活角色一枚胶囊（状态配色 + 间隔进度环，睡眠/工作/游戏/撒娇/勿扰/高峰各自变色，最后一分钟变红脉冲）；悬停展开详情卡（下次活跃时刻、间隔进度、睡眠剩余、工作进度、定点报时、更新循环告警），卡片内可「催一下」立即触发活跃；多角色共享一个挂件自动堆叠，并可自动避让其它插件的注入类挂件（如 TokenStats）；胶囊支持按住拖到任意位置、双击归位，位置按角色持久化（重启保留）；外观（显示时刻/剩余、进度环、角色名、缩放、透明度、避让）可按角色独立配置；可按角色显示/隐藏
- **精美配置面板**：粉色主题，实时状态概览（含本间隔进度条、当前节奏、最近一次倒计时重置来源）+ 模式总开关 + 倒计时挂件设置区 + 多分区可视化配置 + 系统事件接口接管状态提示

## 模式关系

各模式**可叠加同时生效**，按优先级共同影响 AI 行为：

```
工作模式 > 睡眠(绝对压制) > 勿扰 > 峰谷 > 游戏陪伴 > 撒娇
```

- 工作模式为最高优先级，执行任务时自动抑制其他陪伴模式报点，专注任务
- 睡眠期间一切主动报点与定时任务被压制，只有主人发消息或倒计时结束才恢复
- 勿扰开启时自动覆盖撒娇的「主动找主人」行为，只保留「自娱自乐」

## 对话快速上手

直接对 AI 说自然语言即可，AI 会自动调用对应功能：

| 你想做的事 | 说这句话 |
|-----------|---------|
| 设置定时任务 | 「每天早上 8 点提醒我喝水」/「30 分钟后提醒我开会」 |
| 切换报点模式 | 「创建个学习模式，提示词是……」「切换到学习模式」「切回默认报点」 |
| 报点节奏独立 | 「把学习模式设为独立计时，间隔 5 分钟」 |
| 控制节假日豁免 | 「国庆假期别停报点」（由节假日表自动判断，无需 AI 操作） |
| 进入游戏陪伴 | 「进入游戏模式，30 秒一次」 |
| 睡觉 | 「我要睡觉了，明天 9 点叫醒我」/「晚安，睡到自然醒」（等主人发消息） |
| 勿扰 | 「开启勿扰，我要忙一会儿」 |
| 撒娇 | 「开启撒娇模式」 |
| 控制峰谷 | 「开启/关闭峰谷模式」 |
| 调整活跃 | 「把活跃间隔调到 2 分钟」 |
| 执行工作任务 | 直接下达任务即可，AI 自动进入工作模式（如「帮我写个脚本统计文件数量」） |

## 配置说明

### 模式总开关

| 总开关 | 关闭后效果 |
|--------|-----------|
| 游戏陪伴 / 睡眠 / 勿扰 / 撒娇 / 峰谷 | 该模式函数不再暴露给 AI，提示词不再注入 |
| 工作模式 | 无法进入工作模式 |
| 自定义报点 / 定时任务 / 活跃间隔 / 定点报时 | 对应函数全部隐藏 |


### 面板交互

| 项 | 说明 |
|----|------|
| 📖 插件说明 | 模块属性上的说明只保留一句话（不再常驻占半屏），完整功能说明折叠在面板顶部，点「▸ 展开」查看、点「▾ 收起」关掉，不影响任何开关 |
| 区块折叠 | 定时任务 / 游戏陪伴 / 撒娇 / 睡眠 / 勿扰 / 峰谷 / 工作模式 七块内容可各自收起展开；对应的「模式总开关」关闭时默认自动收起（标题行会标注「总开关已关」），点「▸ 展开」仍可查看与编辑，展开按钮不会改变总开关 |

### 活跃机制

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 基础间隔 | 周期报点基础间隔（秒） | 90 |
| 随机偏移 | 间隔随机偏移范围（秒） | 30 |
| 间隔倍数 | 连续报点的间隔翻倍倍数 | 3 |
| 最大翻倍次数 | 间隔最多翻倍次数 | 4 |
| 群聊/私聊消息重置倒计时 | 群聊消息、非主人私聊也视为互动并重置倒计时（睡眠中除外） | 开启 |
| 隐式注入 | 函数文档按需加载（省 token） | 关闭 |

间隔算法：`下次间隔 = (基础间隔 ± 随机偏移) × 间隔倍数 ^ min(连续触发次数, 最大翻倍次数)`，收到主人消息（及开启「群聊/私聊消息重置倒计时」后的群聊/他人私聊消息）后连续次数重置为 0。

> 「报点模式」中开启了**独立计时**的自定义模式不使用上表参数，而是用该模式自己的一组参数；切换模式即切换报点节奏，挂件倒计时也会立即按新节奏对齐。

### 倒计时挂件

| 项 | 说明 | 默认值 |
|------|------|--------|
| 显示开关 | 显示/隐藏本角色胶囊（挂件详情卡内也可单独隐藏） | 开启 |
| 显示时刻而非剩余倒计时 | 关闭=显示剩余时间；开启=显示下次活跃时刻（挂件内点击胶囊可随时切换） | 关闭 |
| 显示间隔进度环 | 胶囊上的报点进度环 | 开启 |
| 多角色时显示角色名 | 只有一个角色时不显示名字 | 开启 |
| 自动避让其它插件挂件 | 探测 TokenStats 等注入挂件并整体让开 | 开启 |
| 缩放 / 透明度 | 60-160% / 30-100%（按角色独立保存） | 100% / 100% |
| 胶囊位置 | 默认跟随右上角编组；按住拖到任意位置即成为该角色的自由位置，双击归位 | 编组 |

### 五种模式参数

| 模式 | 参数 | 默认值 |
|------|------|--------|
| 游戏陪伴 | 查看间隔（秒） | 60 |
| 睡眠 | 默认睡眠时长（小时:分钟）、群聊静默开关 | 8h / 开 |
| 峰谷 | 高峰时段（北京时间）、生效星期、节假日豁免 | 9-12、14-18 / 周一至周五 / 开 |
| 勿扰 | 允许 AI 自主做的事 | 玩浏览器、网络搜索、生图、Q群聊天 |
| 撒娇 | 最短活跃间隔（秒）、智能节流（秒） | 20 / 60 |

### 报点模式：独立计时

| 项 | 说明 |
|----|------|
| 独立计时开关 | 每个自定义报点模式一个开关；开启后该模式使用自己的一组报点参数，各模式之间互不影响 |
| 独立参数 | 基础间隔（秒，≥10）、随机偏移（秒）、间隔倍数、最大翻倍次数 |
| 生效方式 | 切到该模式即按它的节奏报点；切回默认/其它模式即用回全局或对方的节奏 |

### 峰谷：节假日豁免

| 项 | 说明 |
|----|------|
| 节假日豁免 | 开启（默认）后，命中节假日列表的当天**全天视为谷价**，峰谷不生效、照常自主活跃；关闭则任何日期都按高峰时段抑制 |
| 节假日表 | 内置 2026 年官方放假安排（元旦 1/1-1/3、春节 2/15-2/23、清明 4/4-4/6、劳动节 5/1-5/5、端午 6/19-6/21、中秋 9/25-9/27、国庆 10/1-10/7），可在配置面板添加/移除，或一键「恢复内置节假日表」 |
| 在线校准（需联网） | 按钮式立即拉取当年官方节假日；另有「每年首次启动自动在线校准」开关（默认关闭）。请求失败静默忽略，离线使用不受影响 |
| 调休补班 | 不做特殊处理（无视调休）：补班的周末仍按「生效星期」判断为周末，不参与峰谷 |

### 定时任务：临时任务清理

| 项 | 说明 |
|----|------|
| 触发即删除 | 临时任务（N 分钟后触发一次）触发后自动从任务列表删除，不会留下禁用条目；触发提示会告知 AI 无需手动清理 |
| 工作会话清理 | 可选开关（默认关闭）：工作模式结束/中止时，清理本次会话期间创建且**尚未触发**的临时任务。若你的临时任务本就安排在工作结束之后触发，请保持关闭 |

## 注意

- **需要 Alife.Client ≥ 4.5.0**（`globalUI` 全局 UI 注入项、容器并发修复均在此版本引入）
- 依赖 `Alife.Function.FunctionCaller`（Xml 函数调用底座）与 `Alife.Function.SystemEvent`（引用其 `ISystemEventService` 接口；**插件需要处于加载状态，但不要在角色模块里勾选启用它**）
- 与官方 `Alife.Function.SystemEvent` 功能重叠：请只在角色模块里启用本插件。官方若同时启用，会双套周期报点，且系统事件接口被官方实例占用，QQ 插件的群聊/私聊重置会走官方实现（配置面板会用红/绿提示当前接管状态）
- 切换「隐式注入」开关后需重载插件（或重启角色活动）才生效
- 高峰时段按北京时间（UTC+8）判断星期与小时，不依赖系统时区；生效星期默认周一至周五，可在配置面板逐日开关；节假日豁免同样按北京时间日期判断，节假日表可在配置面板维护（或开启每年自动在线校准，需联网，默认关闭）
- 倒计时挂件由**框架的 globalUI 注入项**在客户端窗口内直接渲染（Blazor 组件），**不再注入页面脚本、不再开本地 HTTP 服务、不再使用端口/令牌/心跳**，因此没有 ElectronNET IPC 竞争与端口占用问题；与其它 `globalUI` 组件一样位于客户端的悬浮层（层级低于 Ant Design 弹窗）
- 挂件里的拖拽与「避让其它插件挂件」会通过 `IJSRuntime` 借用浏览器 API（量元素矩形/视口/探测 `#tstats-root`），全部做了失败兜底：JS 不可用时挂件照常显示，只是不做边界钳制与避让
- 周期报点、定时任务、睡眠与工作模式**回归框架的模块更新循环**（`OnUpdate`）：Alife.Client 4.5.0 已把容器遍历与增删用锁串行化，原先「Collection was modified 导致更新循环永久停止」的根因已修复，故 4.5.3/4.5.4 的自有循环兜底已撤除。若仍长时间收不到更新回调，挂件胶囊会显示红点、配置面板会提示「停用后重新激活角色」（只读告警，不再自行兜底）
