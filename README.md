# 主动事件增强 (SystemEventBoost)

以官方「主动事件」机制为基础进行增强，让 AI 的自主活动更聪明、更懂主人。完整继承官方的周期报点算法（基础间隔 ± 随机偏移 × 翻倍次数），并在此基础上叠加了定时任务、自定义报点模式与五种可叠加的陪伴模式，全部可由 AI 通过自然语言自主开启与关闭。

## 功能特性

- **定时任务**：支持循环任务（每天 / 每周几固定时分触发）与临时任务（N 分钟后触发一次），让 AI 定时提醒主人或自主做任何事
- **自定义报点模式**：可创建多个自定义报点提示词（如「学习模式」「新闻模式」），与默认官方报点自由切换；报点间隔算法不变，仅提示词改变
- **游戏陪伴模式**：按自定义间隔主动查看屏幕游戏画面，给予鼓励与建议（AI 自动使用深度视觉）
- **睡眠模式**：设定时间内 AI 不再主动活动，直到主人发消息或倒计时结束自动恢复；可开关「群聊静默」——睡眠期间群聊消息替换为静默占位，AI 不回复
- **DeepSeek 峰谷模式**：高峰时段（默认北京时间 9-12 点、14-18 点）自动停止自主活跃节省资源，时段可自定义
- **勿扰模式**：AI 自主活动但不打扰主人（禁止 speak/qchat 标签），可自定义允许 AI 做的事
- **撒娇模式**：更粘人主动找主人，最短活跃间隔 20 秒 + 智能节流（无互动自动拉长间隔防空转）
- **隐式注入开关**：开启后函数文档不直接注入系统提示词，AI 先调用 `<systemeventboost/>` 按需加载（省 token，渐进式）
- **精美配置面板**：粉色主题，实时状态概览 + 四大分区可视化配置

## 模式关系

五种模式**可叠加同时生效**，按优先级共同影响 AI 行为：

```
睡眠(绝对压制) > 勿扰 > 峰谷 > 游戏陪伴 > 撒娇
```

- 睡眠期间一切主动报点与定时任务被压制，只有主人发消息或倒计时结束才恢复
- 勿扰开启时自动覆盖撒娇的「主动找主人」行为，只保留「自娱自乐」

## 对话快速上手

直接对 AI 说自然语言即可，AI 会自动调用对应功能：

| 你想做的事 | 说这句话 |
|-----------|---------|
| 设置定时任务 | 「每天早上 8 点提醒我喝水」/「30 分钟后提醒我开会」 |
| 切换报点模式 | 「创建个学习模式，提示词是……」「切换到学习模式」「切回默认报点」 |
| 进入游戏陪伴 | 「进入游戏模式，30 秒一次」 |
| 睡觉 | 「我要睡觉了，明天 9 点叫醒我」/「晚安，睡到自然醒」（等主人发消息） |
| 勿扰 | 「开启勿扰，我要忙一会儿」 |
| 撒娇 | 「开启撒娇模式」 |
| 控制峰谷 | 「开启/关闭峰谷模式」 |
| 调整活跃 | 「把活跃间隔调到 2 分钟」 |

## 配置说明

### 活跃机制

| 参数 | 说明 | 默认值 |
|------|------|--------|
| 基础间隔 | 周期报点基础间隔（秒） | 90 |
| 随机偏移 | 间隔随机偏移范围（秒） | 30 |
| 间隔倍数 | 连续报点的间隔翻倍倍数 | 3 |
| 最大翻倍次数 | 间隔最多翻倍次数 | 4 |
| 隐式注入 | 函数文档按需加载（省 token） | 关闭 |

间隔算法：`下次间隔 = (基础间隔 ± 随机偏移) × 间隔倍数 ^ min(连续触发次数, 最大翻倍次数)`，收到主人消息后连续次数重置为 0。

### 五种模式参数

| 模式 | 参数 | 默认值 |
|------|------|--------|
| 游戏陪伴 | 查看间隔（秒） | 60 |
| 睡眠 | 默认睡眠时长（小时:分钟）、群聊静默开关 | 8h / 开 |
| 峰谷 | 高峰时段（北京时间） | 9-12、14-18 |
| 勿扰 | 允许 AI 自主做的事 | 玩浏览器、网络搜索、生图、Q群聊天 |
| 撒娇 | 最短活跃间隔（秒）、智能节流（秒） | 20 / 60 |

## AI 函数

| 函数 | 说明 |
|------|------|
| `<createscheduledtask name message hour minute daysofweek/>` | 创建循环定时任务 |
| `<createonetimetask name message afterminutes/>` | 创建临时定时任务 |
| `<removescheduledtask name/>` / `<listscheduledtasks/>` | 删除 / 列出定时任务 |
| `<createreportmode name prompt/>` | 创建自定义报点模式 |
| `<switchreportmode modename/>` | 切换报点模式（默认/官方可切回） |
| `<listreportmodes/>` / `<removereportmode name/>` | 列出 / 删除报点模式 |
| `<entergamemode intervalseconds/>` / `<exitgamemode/>` | 进入 / 退出游戏陪伴模式 |
| `<gosleep wakeuptime durationminutes waitforuser/>` / `<wakeup/>` | 睡眠 / 唤醒 |
| `<enabledonotdisturb actions/>` / `<disabledonotdisturb/>` | 开启 / 关闭勿扰 |
| `<enablecutemode minintervalseconds/>` / `<disablecutemode/>` | 开启 / 关闭撒娇 |
| `<setpeakmode enabled/>` | 切换峰谷模式 |
| `<setactiveinterval intervalseconds/>` | 调整活跃间隔 |
| `<awake time remark/>` / `<await second/>` | 定点报时 / 等待（官方机制） |

```
Alife.Plugin.SystemEventBoost/
├── Alife.Plugin.SystemEventBoost.json   # 市场注册清单

```

## 注意

- 依赖 `Alife.Function.FunctionCaller`（Xml 函数调用底座）
- 与官方 `Alife.Function.SystemEvent` 功能重叠，建议只启用本插件（避免双套周期报点）
- 切换「隐式注入」开关后需重载插件（或重启角色活动）才生效
- 高峰时段按北京时间（UTC+8）判断，不依赖系统时区
